# Helm — project instructions

## Auto-commit

After completing any change to this repo, commit it automatically without asking:

1. Stage the changed files (`git add` the specific paths you touched — not `git add -A` blindly).
2. Commit with a conventional-commit message (`feat:` / `fix:` / `chore:` / `docs:` ...).
3. One logical change per commit; batch related file edits into a single commit.

Do not push unless explicitly asked.
